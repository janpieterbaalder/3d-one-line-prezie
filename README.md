## ▓ WAT.IS ▓

**3D One Line Prezi** is de driedimensionale broer van
[One Line Prezi](https://github.com/janpieterbaalder/One-Line-Prezi). Je dia's
hangen als kaarten in een 3D-ruimte. Eén lijn tekent de eerste tekening, maakt
zich los van het papier, vliegt door de ruimte naar de volgende tekening en
tekent verder. De camera vliegt achter de pen aan, draait om de tekeningen heen
en laat aan het eind het hele lijn-kunstwerk zien.

Dezelfde bibliotheek met one-line-tekeningen en hetzelfde handgeschreven
**one-line-font** als in de 2D-versie zitten erin, en 2D-presentaties kun je
gewoon openen: ze worden automatisch omgezet naar 3D.

```
┌─────────────────────────────────────────────────────────┐
│  ♡  FEATURES.sys                              [_][□][×] │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ✧  Camera vliegt in 3D van en naar elke tekening       │
│  ✧  De lijn is een echte 3D-lijn (buis) door de ruimte  │
│  ✧  Bibliotheek als echte 3D-lijntekeningen             │
│  ✧  Eigen SVG's (plat, gebogen of als reliëf)           │
│  ✧  Tekst als lijn (one-line-font) — ook in 3D          │
│  ✧  Tekst, afbeeldingen en video's (bestand, link,      │
│       YouTube) — de lijn tekent eerst een kader         │
│  ✧  2D One Line Prezi-presentaties openen (omzetten)    │
│  ✧  Export als één los HTML-bestand                     │
│  ✧  Opnemen als video (MP4/WebM, 1920 × 1080)           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### ▒ CREATIEVE EXTRA'S ▒

| | |
|:---|:---|
| **3D-bibliotheek** | De tekeningen uit One Line Prezi als echte 3D-lijntekeningen: kompas, zandloper, wegwijzer, anker, appel, boek(en), boom met vallend blad, weegschaal, Rubik's kubus, lego, taart, steeksleutel, vraagteken, diamant en diagrammen. Mensen en handen krijgen automatisch een 3D-reliëf. Shift+klik in de bibliotheek = het platte 2D-origineel. |
| **Dia's die pas verschijnen bij aankomst** | Onderweg zie je alleen de lijn; de kaart van een dia verschijnt zacht als de camera aankomt. Het kader kan ook *alleen een rand* of *onzichtbaar* zijn. |
| **Video en afbeelding** | De pen tekent eerst een kader, daarna verschijnt de afbeelding of start de video. Video als bestand, via een link (Dropbox, OneDrive, Google Drive…) of YouTube, met automatisch starten, geluid en herhalen. |
| **Video-editor** | Klik bij een video op *✂ Afspelen en stukjes kiezen* (of dubbelklik op de video). Speel de video af, markeer een stuk met `I` en `O` (of de knoppen *[ Begin hier* en *Einde hier ]*) en kies *laten zien* of *weghalen*. Op de tijdlijn sleep je de randen van een stukje bij. In de presentatie speelt de video alleen de gekozen stukjes, achter elkaar. Stukjes uit de 2D-app komen mee. |
| **3D-vormen uit één lijn** | Bol, hart, knoop, veer, DNA, kubus (Hilbert-kromme), Lissajous, wervelwind, zandloper en heuvels — wiskundig allemaal één doorlopende lijn. |
| **Tekeningen buigen** | Leg een 2D-tekening bol, laat hem golven, vouw hem om een cilinder, draai hem of zet elk pad op een eigen diepte (lagen). |
| **Lijnreizen** | De lijn tussen twee dia's kan vloeiend gaan, een looping maken, als kurkentrekker draaien, golven of recht gaan. |
| **Camera-regie** | *Achter de pen aan* (drone-shot), *Zweefvlucht* (Prezi-achtig uit- en inzoomen) of *Rechtstreeks*. Tijdens het tekenen: rustig, meekijken of inzoomen (begint dicht op de pen en zoomt uit). |
| **Werelden** | 15 werelden: Papier, Nacht, Ruimte (zonder sterren), Synthwave, Noorderlicht, Oceaan, Y2K pastel, Suikerspin, Bos, Woestijn, Krijtbord, Mist, Blauwdruk, Zonsondergang en Zwart-wit. Met *Wereld aanpassen* kies je zelf de luchtkleuren, kaart-, lijn- en tekstkleur, sterren, stofjes, rasterbodem en mist. Per dia kan de lucht van kleur verschieten (*sfeer*). |
| **Lijnstijlen** | Inkt (plat, zoals op papier), Neon (gloeiend, met een schuif voor de sterkte van de gloed) en Klei (3D met licht en schaduw). Tekenen en vliegen gaan met dezelfde pen in één rustig tempo. |
| **Indelingen** | Zet alle dia's in één klik als rij, wenteltrap, carrousel, golf, tunnel of sterrenstelsel. |
| **Opening & slot** | De lijn komt van ver aanvliegen; aan het eind vliegt hij de ruimte in en draait de camera om het hele kunstwerk. |
| **Spookspoor** | De rest van de lijn is vaag zichtbaar, zodat je publiek al ziet waar de reis heen gaat. |
| **Overzicht** | Druk op **O**: de camera zoomt uit naar alles; klik op een tekening en je vliegt erheen. |
| **Om de tekening heen kijken** | Sleep tijdens het presenteren met de muis; loslaten en de camera veert terug. |
| **Vonkjes, parallax & geluid** | Sterretjes bij de pen, het beeld beweegt licht mee met de muis, en optioneel het zachte krassen van de pen en een zucht tijdens het vliegen. |
| **3D-bril** | Druk op **A** voor een rood/cyaan-anaglief: met een 3D-brilletje komt alles echt naar voren. |

## ▓ INSTALL.exe ▓

```bash
git clone https://github.com/janpieterbaalder/3d-one-line-prezie.git
cd 3d-one-line-prezie
npm install
npm start
```

Zonder Electron, in een gewone browser:

```bash
npm run serve
```

en open daarna `http://127.0.0.1:8317/`. (Via een webserver, niet door
`index.html` dubbel te klikken: de export en de lettertypen worden dan geladen.)

### ▒ BUILD .exe ▒

```bash
npm run build
```

Het installatiebestand verschijnt in `./dist/`.

De editor heeft twee weergaven (wissel met **Tab**):

- **🌐 Wereld** — draai om alle dia's heen. Slepen = draaien, rechts slepen =
  schuiven, scrollen = zoomen, klik = dia kiezen, dubbelklik = bewerken,
  Shift + slepen = dia verplaatsen.
- **▭ Dia bewerken** — de camera kijkt recht op de dia; sleep elementen,
  maak ze groter met het hoekje en draai ze met het bolletje.

## ▓ KEYBOARD.sys ▓

**Presenteren**

| Toets | Actie |
|:---:|:---|
| `F5` / `Shift+F5` | Presenteren vanaf het begin / vanaf deze dia |
| `→` / `Spatie` / `Klik` / vegen | Volgende (tijdens het tekenen: tekening meteen af) |
| `←` / rechtermuisknop | Vorige dia — de lijn spoelt terug en tekent opnieuw |
| `Home` / `End` | Eerste / laatste dia |
| `3` `Enter` | Naar dia 3 (de lijn spoelt snel vooruit) |
| `O` | Overzicht van de hele lijn; klik op een dia om erheen te vliegen |
| `slepen` / `scrollen` | Om de tekening heen kijken / zoomen |
| `A` | 3D-bril (rood/cyaan) |
| `M` | Geluid aan/uit |
| `K` / klik op de video | Video afspelen / pauzeren |
| `→` op een dia met video | Eerst de video starten, daarna volgende dia |
| `B` / `W` | Zwart / wit scherm |
| `F` | Volledig scherm |
| `?` | Sneltoetsen |
| `Esc` | Stoppen |

**Bewerken**

| Toets | Actie |
|:---:|:---|
| `Tab` | Wereld ⇄ dia bewerken |
| `Ctrl+S` / `Ctrl+Shift+S` | Opslaan / opslaan als |
| `Ctrl+O` | Openen (ook 2D One Line Prezi-bestanden) |
| `Ctrl+Z` / `Ctrl+Y` | Ongedaan maken / opnieuw |
| `Ctrl+D` | Element of dia dupliceren |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Element kopiëren / knippen / plakken (ook naar een andere dia) |
| `Ctrl+V` | Ook: afbeelding of SVG-code plakken |
| `pijltjes` | Element 1 px verschuiven (`Shift`: 10 px); anders: vorige/volgende dia |
| `Delete` | Element verwijderen |
| `F1` | Hulp |

> Wijzigingen worden automatisch in de browser bewaard; bij de volgende start
> staat je werk er weer.

## ▓ BESTANDEN ▓

- **Opslaan** schrijft een `.json` met alles erin (ook tekeningen en afbeeldingen).
- **2D importeren**: open een presentatie uit One Line Prezi. Tekeningen,
  kleuren, tekst als pad, tekstblokken, ondertitels en afbeeldingen komen mee;
  ook video's en YouTube; de dia's worden in een golf door de ruimte gezet.
- **Exporteren als HTML**: één bestand waarin Three.js, de 3D-motor, de
  lettertypen en de presentatie zitten. Dubbelklikken = presenteren, ook offline.
- **Opnemen als video**: de presentatie speelt zichzelf af in 1920 × 1080 en
  wordt opgenomen (MP4 als de browser dat kan, anders WebM). Met geluid aan
  wordt het pengeluid meegenomen.

## ▓ TECH.STACK ▓

```
┌─ RUNTIME ──────────────────────────┐    ┌─ BUILD ──────────────────┐
│  ▓ Three.js r180 (assets/vendor)   │    │  ▓ electron-builder       │
│  ▓ Electron 40 + lokale webserver  │    │  ▓ esbuild (three-bundel) │
│  ▓ Vanilla HTML / CSS / JS         │    │  ▓ NSIS (Windows)         │
└────────────────────────────────────┘    └───────────────────────────┘
```

| Bestand | Wat |
|:---|:---|
| `index.html` | De editor (opmaak en stijl) |
| `assets/js/engine.js` | De 3D-motor: SVG lezen, lijn als buis, 3D-vormen, camera, presentatie. Wordt ook in de HTML-export gezet. |
| `assets/js/models3d.js` | De 3D-lijntekeningen van de bibliotheek |
| `assets/js/editor.js` | De editor: dia's, elementen, panelen, bestanden, export, video |
| `assets/svglibrary.js`, `assets/onelinefont.js` | Bibliotheek en one-line-font, overgenomen uit One Line Prezi |
| `assets/vendor/three.min.js` | Three.js als los script (`npm run build:three` maakt hem opnieuw) |
| `tools/serve.js` | Kleine webserver om in de browser te testen |
